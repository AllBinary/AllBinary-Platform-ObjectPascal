                             AllBinary Platform Object Pascal

What is it?

This repository contains code generated by the AllBinary Platform for ArkTS and 
React Native support in Object Pascal.  This repo is used to allow developers 
to skip the Object Pascal code generation step.

What are some examples game with this Object Pascal code?

https://allbinary.itch.io (The downloads with "-ts" in the filename are Object Pascal only builds. Currently that only includes nothing. Also the Object Pascal builds are not available on Google Play or other stores.)
